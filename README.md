# 🦞 OpenClaw Team Hub

لوحة تحكم رسومية لإدارة فريق OpenClaw — إضافة الأعضاء، التحكم بالصلاحيات، إدارة القنوات والنماذج.

## المميزات

- **👥 إدارة الفريق** — إضافة أعضاء جدد وتعيين صلاحياتهم
- **🛡️ صلاحيات متدرجة** — مالك (صلاحية كاملة) / عضو (محادثة فقط)
- **📋 مجموعات الوصول** — تنظيم الأعضاء في مجموعات
- **🤖 وكلاء مخصصون** — إنشاء وكلاء بصلاحيات مختلفة
- **📡 القنوات** — عرض وإدارة القنوات المتصلة
- **🧠 النماذج** — إضافة نماذج ذكاء اصطناعي جديدة

## التشغيل

```bash
git clone https://github.com/Xmood96/openclaw-team-hub.git
cd openclaw-team-hub
npm install
node server.js
```

ثم افتح `http://localhost:3780`

## متطلبات التشغيل الدائم

```bash
crontab -e
# أضف هذا السطر:
*/5 * * * * cd /path/to/openclaw-team-hub && node server.js > /tmp/team-hub.log 2>&1
```
